Ask Claude what your Makino cell is doing.

MakinoMCP gives Claude a read-only view of a Makino MAS-A5 cell: which machines are running, which alarms are open, what the pallets are doing, and what the log files say.

Download for Windows How to set it up

Free and open source (MIT). It only reads: it never changes the cell, the database or any file.

Ask in plain words

Claude picks the tools it needs, reads the cell, and answers with what matters: what is running, what is stuck, and for how long.

What it reads

  • The cell's Makino database (SQL Server): device status, alarms, utilisation, recent activity, orders, pallets, tools, part routings and production counts.
  • Folders you choose to share, for example the cell PC's C:\Makino\Log shared read only. Claude can list, read and search text files there, and nowhere else.

Some numbers in the cell have no published meaning. Where the meaning of a status was worked out from the installed MAS-A5 software it is shown in words; anything without a known meaning appears as code N.

The read-only promise

MakinoMCP has no tool that writes, sends, deletes or changes anything. Database access is fixed SELECT queries, and there is no “run this SQL” tool. A database login that can only read is recommended, so the database enforces the promise too.

Set it up

You need Windows 10 or 11, network access to the cell's SQL Server, and a SQL or Windows login that can read the Makino database.

  1. Download MakinoMCP-<version>-win-x64.zip with the button at the top, or from the latest release, and check it against the .sha256 file on the release page.
  2. Unzip it into a folder on the PC, for example %LOCALAPPDATA%\Programs\MakinoMCP, and run MakinoMCP.exe there. Or, if your shop keeps a copy on a share, open MakinoMCP.exe on the share once: it installs MakinoMCP on the PC and opens its setup window.
  3. Enter the server, database and login, choose Test connection, add any folders to share, then Save.
  4. Each PC's copy keeps itself up to date from GitHub, and Claude runs that copy, not the share.
  5. Copy the lines the setup window shows into Claude, as below.

Windows SmartScreen may warn about an unknown publisher, because the program is not code-signed. Choose More info, then Run anyway, only if you downloaded it from the release above.

Connect Claude

The easy way, on each PC: open MakinoMCP.exe and use the Use MakinoMCP in Claude on this PC switch. On adds MakinoMCP to Claude Code (including the Code tab of the Claude desktop app) and to Claude desktop's Cowork for your Windows account; quit Claude fully (from the tray icon) and reopen it to see the tools. It needs no terminal: on a PC with only the Claude desktop app, it uses the Claude Code that comes with the app. Off removes it from Claude on this PC and stops it. Other PCs aren't affected. To connect by hand instead:

Claude Code, once per PC, in PowerShell (needs the claude command line; the setup window shows it with your folder filled in)

claude mcp add --scope user makino -- "$env:LOCALAPPDATA\Programs\MakinoMCP\MakinoMCP.exe" serve

Claude Cowork or Claude Desktop: add to mcpServers (in the app's settings, search for "developer", then Edit Config), then quit Claude from the tray icon and reopen it

"makino": { "command": "C:\\Users\\you\\AppData\\Local\\Programs\\MakinoMCP\\MakinoMCP.exe", "args": ["serve"] }

If the file already has an mcpServers section, add the entry inside it. If Cowork doesn't list the MakinoMCP tools after a restart, open an issue.

What to ask

  • What is every machine in the cell doing right now?
  • What needs a person right now?
  • Which tools are near the end of their life, and which alarmed this week?
  • How many parts did we make this week, and is this part's tooling in the machines?
  • Which alarms keep coming back this week, and on which machine?
  • Did the cell sit idle overnight? Show me the gaps.
  • Which orders are still open, and where are their pallets?

Tools Claude gets

ToolWhat it gives Claude
get_cell_overviewEvery device: connection, emergency stop, status, recovery request, mode, current action, pallets, open alarms, last activity. Machines add tool status, CNC run state, operator call, current job and program; stations add the instruction they show; work in progress shows since when and its planned finish, and closed devices are marked. The cell's duty, scheduled power-off and recovery policy come with it, and historyDays says how long the cell keeps PMC alarms and results.
get_alarmsOpen and recent PMC and CNC alarms, newest first.
get_alarm_summaryAlarms grouped by device and number, most frequent first.
get_utilizationBusy, idle, down and error hours per device and day, the console's result-based utilization, spindle time and OEE; optional shift filter.
get_recent_activityMachining, work-set and transport results, to spot gaps.
get_ordersQueued and finished orders, with quantities, status, start, priority and what each waits for; optionally the archive.
get_palletsEach pallet's status, location, priority and fixtures with their states.
get_toolsWhich tools need attention and where a tool is: status, life left, measured size.
get_tool_changesWhat changed in the tool data, newest first. Routine life updates and tools that only reached their life warning are counted, and listed on request. Looks back 3 days unless asked.
get_tool_alarmsWhich tools alarmed lately, with their life and size then.
get_tool_movementsTools put into or taken out of the machines, with who and why.
get_part_routingHow a part is made, and whether its tools are on the machines. The tool check is approximate: it uses the tool set the cell registered for each program (subprograms included) and doesn't check remaining life.
get_productionParts completed, scrapped and in process per order and per day.
get_attentionOne list of what is waiting on a person right now, including waiting work no device can take.
get_pallet_diagnosisWhy a pallet's work isn't moving, by the console's own Pallet Diagnosis rules.
get_work_setWhat each work-set station asks the operator to do.
get_macro_valuesMacro variable values the machines' programs uploaded.
find_serialWhere a part serial number was recorded.
explain_ade_fileWhy an automatic data entry file was rejected, or what it will do.
list_shared_foldersThe folders you shared, and whether they are reachable.
list_filesFiles and subfolders in a shared folder.

search_filesPlain-text search across a shared folder.

Limits

  • History is short: historyDays in the overview says how many days the cell keeps PMC alarms and results (90 days unless the cell is set otherwise), daily production counts are kept about three months, and CNC alarms are limited to about the last 200 regardless.
  • Tool lengths are in the cell's own unit (inch on some cells); each result says which.
  • Results are capped at 500 rows, and file reads at 256 KB, unless you change the limits in the settings file.

Security

  • The database password is stored in plain text in MakinoMCP.settings.json. Protect that folder, and prefer a read-only login or a Windows login.
  • Whatever is in the database and the shared folders can appear in your Claude conversation. Share only folders you are happy for Claude to read.
  • Each PC's copy updates itself: at most every 6 hours it asks GitHub, anonymously, for a newer release, then downloads it, checks its SHA-256 and installs it. Nothing about you, the PC or the cell is sent. Turn it off in the setup window.
